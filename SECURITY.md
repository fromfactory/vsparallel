# Security policy

## Supported versions

Security fixes are provided for the latest published VSParallel release. Users
should update to the newest release before reporting a problem that may already
be fixed.

## Report a vulnerability privately

Please use [GitHub's private vulnerability reporting form][report] for issues
that could affect confidentiality, integrity, availability, updater trust, or
the local privacy boundary. Do not include sensitive details in a public issue.

Include the affected VSParallel version and operating system, the expected and
observed behavior, reproduction steps, and the impact you believe is possible.
Please keep exploit details private until a fix and disclosure plan are agreed.

Ordinary bugs and feature requests that have no security or privacy impact can
be filed in the public issue tracker.

[report]: https://github.com/fromfactory/vsparallel/security/advisories/new
